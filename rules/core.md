# 計算與證據規則

- 每筆欄位記錄原始文字、正規化值、文件代號、頁碼、定位及判讀狀態。不得以 OCR 信心分數取代人工或圖像核對。
- `null` 表示缺值，零分是有效分數；不得因零分排除學分。學分加權平均 = 有效且納入課程的 Σ(學分×分數) / Σ學分。學分必須大於零；零學分課程不參與加權。
- 成績單的實得學分與數值成績的修習學分分別保存；不及格可能未取得學分，仍須依已確認政策保留其分數與修習學分。跨學期數值核對優先使用逐課原始學分及分數，不以實得學分加權已四捨五入的學期平均。P、W等符號保留原文，不自動轉零或百分制，排除須有明確理由。
- 缺少分數、學分或採計決定時，阻擋正式平均；可提供明確標示的暫估，但 CLI 採嚴格阻擋模式。不把等第自行換成百分制。
- 成績制度、學期範圍、重修、抵免、通識及體育採計規則須已確認。只有規則狀態為 confirmed 才可計算；這代表呼叫端已核實政策，不代表符合獎學金資格。
- 申請表自填成績與正式成績單分別保存，有差異時列出兩方證據，不能覆寫或挑較高者。**申請表自填的平均、歷年必修平均或衍生分數只作比對證據，不得直接寫入正式 Word 成績欄位。**
- 正式 Word 的成績/平均欄位必須來自「已核對的 Excel 計算結果」或「依已確認規則完成的獨立驗算」。若兩者同時存在且不同，阻擋該欄正式寫入，保留兩個結果並回報差異；不得改抄申請表數字來消除衝突。
- 年級優先依正式入學年月與目標學年度推算。若推算年級與申請表、成績單標示或其他來源不同，先提出至少「依入學年月推算值」與「來源標示值」兩個選項，說明依據並詢問使用者；在使用者選定前不得擅自決定正式 Word 年級。已由使用者明確確認的個案可直接採確認值。
- 班排名、系排名、年級排名、單學期排名與歷年排名不得互換。排名須保留母體、期間、名次及總人數；名次/人數為位置比例，不等於百分位或資格判定。
- 課名相同或相近不代表重複修課；只標示複核。相同課程紀錄 ID 則阻擋，以免重複計分。
- 字跡不清、跨頁表格、影像截斷標成 uncertain 或 missing，不猜測。保留原始來源及文字版本，修改以衍生檔完成。
