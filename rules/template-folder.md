# 私人範本資料夾規則

本專案有一個由 ChatGPT 專案私人設定保存的「獎學金申請資料整理範本」Google Drive 資料夾。實際 URL/ID 不進 public GitHub。

每次整理開始都必須 live list 該資料夾。資料夾內當下的正式範本檔是唯一格式權威；不能使用上一次下載快取或自行建立的近似檔替代。

## 一對一交付

- 每個正式範本都必須有一個對應成品。
- 保留原副檔名；DOCX 對應 DOCX、XLSX 對應 XLSX，未來若新增其他正式格式亦同。
- 正式結果只由原範本副本填資料產生，不從空白檔重建。
- 不自行新增額外正式輸出格式。

## 不可修改的格式

Excel：公式邏輯、樣式、字型、顏色、框線、數字格式、列高、欄寬、合併、驗證、凍結、隱藏、命名範圍、頁面設定、列印範圍、頁首頁尾、主題。
Word：字型、字級、段落、行距、縮排、表格樣式/欄寬/框線、分節、頁邊距、頁首頁尾、分頁、編號、圖片配置。

只有「填入資料」以及範本明確設計為可重複的申請人模板列/區塊/工作表複製是允許的。不得為了加註來源、QA 或疑義自行增加正式頁面/工作表。

## 驗收

交付前以原始範本對成品做結構/格式比對；Excel 優先使用 format_guard 類檢核，Word 至少核對 section/table/style/paragraph 結構。若無法證明一致，不得聲稱「格式完全一致」。
