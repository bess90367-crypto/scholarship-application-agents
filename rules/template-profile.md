# 已觀察模板（可泛化結構）

模板有 `計算模板`（A1:M23）與 `(勿動!!!!!!!)參數清單表`（A1:R79）。重製時先讀取實際模板版本、儲存格公式、樣式、合併、驗證、隱藏列欄及命名範圍，不能只依此摘要寫入。

原模板 M2 分母排除零分的行為存在缺陷：零分仍應納入採計學分。僅在新的衍生工作簿修正並記錄原式與新式，不改來源模板。公式計算結果須以獨立 Python 計算核對；openpyxl 不會計算公式，沒有重算引擎時明說公式快取未重算，另附靜態驗證值。

參數清單上方統計學相關項目疑似重複，狀態為待複核；不能自行合併、刪除或套用為通用規則。參數工作表原則保留。具體課程映射和資格規則需依當次資料證據確認。

模板的研究方法上、下學期預設各 1 學分，但成績單可能列為 3 學分。保留「模板預設學分」與「成績單學分」及各自來源，列為差異；未確認此模板的採計政策前，不可靜默改成任一方或用來計算正式平均。

課程上、下學期是不同映射鍵，不得刪除「上」「下」字樣後以同名覆寫。課程名稱與學期相同的多筆資料須複核修課次別與來源行，不可自動相加或只保留最後一筆。學號等識別碼始終以文字保存，保留前導零；若來源已被轉成數字，應回查來源，不可猜補位數。

讀取陣列公式時保存公式文字及作用範圍，不可只輸出物件描述。模板分析也要保存數值型別、列高及欄寬，避免無法重建格式。
