# 範本格式權威

公開倉庫中的結構摘要只供 regression test 與欄位理解，**不是**正式輸出的版型來源。每次任務必須從已設定的私人「獎學金申請資料整理範本」資料夾重新取得當下正式範本原檔，以其實際 bytes / OOXML / DOCX 結構為準。

目前已確認範本資料夾至少包含 Word 名單範本與 Excel 平均計算範本，但 Agent 不得把這個數量硬編碼；未來資料夾新增、移除或替換正式範本時，下次整理要自動跟隨。

Excel 成品以原始工作簿直接複製後填值。不得重建近似格式，不得自行修正或重寫範本公式，不得新增非範本工作表。允許的結構動作只限範本本身設計所必要的「複製指定申請人模板工作表以容納實際申請人」與「依確認姓名重新命名該複製頁」；複製頁必須與來源模板工作表格式相同。其餘公式、樣式、列高、欄寬、合併、驗證、隱藏、凍結、命名範圍、頁面設定及列印設定全部保留。

Word 成品同樣以原始 DOCX 複本填入。不得改字型、字級、行距、段落、表格欄寬、框線、頁首頁尾、頁邊距、分節、分頁、編號或其他版面。資料列若範本明確設計為可重複區塊，只能複製該既有區塊的完整格式；不得自行設計新表格。

若資料與範本現有欄位發生衝突，不能為容納資料而修改範本；使用者要求的「格式完全一致」優先。缺漏、歧義、來源差異與不適合塞入範本的資訊只在對話中說明，不另增工作表/頁面/附表。

任何公開規則中記錄的公式缺陷、學分差異或歷史觀察都只能用於 QA；未經使用者另行明確授權，不得因此修改私人範本本身。
