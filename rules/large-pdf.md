# 大型 PDF 完整讀取策略

目的：不能因 Drive 連接器或單檔大小限制直接略過任何當次來源。

## Fallback 順序

1. **Drive 索引文字**：先嘗試取得 provider 已解析的完整可讀文字；若只有摘要、片段或無頁面覆蓋，不算完整。
2. **原始檔串流下載**：檔案在當前 raw-download 上限內時，下載原始 PDF 到本機工作區，取得頁數並逐頁處理。
3. **同內容可讀副本**：若原檔超限，在同一學期資料夾及可存取 Drive 中搜尋同一原檔的分卷、壓縮版、逐人分檔或其他可驗證的衍生副本；必須能對應回原檔且覆蓋完整。
4. **Work/瀏覽器路徑**：若 default connector 因檔案大小無法取得 bytes，使用可用的 Work/Computer/Cloud Browser 下載原檔，再用本機工具按頁數或檔案大小切成多份，逐份轉文字並建立 page map。
5. **人工前處理才是最後手段**：只有前述路徑都不可用時，才請使用者提供分割/壓縮副本。建議每一分檔小於 200 MiB，並以原檔名加 `_part01`、`_part02` 命名，保留原頁順序。

## 完整性閘門

每個 PDF 最終必須有：來源 ID、總頁數、每頁處理狀態、抽取方式與申請人邊界。只取得文字摘要或部分頁面不能算完整。任何未讀頁都使整批保持「部分完成」。

## 安全

不可用舊年度資料補當次未讀大型 PDF；不可因檔名相似直接視為同一內容。衍生副本必須用頁數、內容邊界或可驗證資訊確認覆蓋。
