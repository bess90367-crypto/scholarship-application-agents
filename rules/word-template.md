# Word 原格式與人工保留區

適用 REQ-022；範本來源依 REQ-017 與 rules/template-folder.md。每次產出申請名單 Word，直接複製使用者指定歷史 DOCX，只替換有來源依據的當期申請人資料與允許更新的標題。保留字型、字級、顏色、段落、表格欄寬、合併、邊框、頁首頁尾、頁面及列印設定；不得重新設計或新增說明區。表格容量不足時只複製同類原始列，保持列與儲存格格式，並檢查跨頁排版。若某獎項的唯一資料列本身是跨欄合併的「無申請者」占位列，當期即使有申請人，也不得為填入欄位而自行取消合併、拆格或重建資料列；該 Word 區段保持原結構並清除過期占位文字，在對話中回報無法映射，其他可映射正式範本照常填入。原名單個資不得殘留於新的申請人區。

「目前系上各獎學金狀況」與「各獎學金申請人數」由使用者人工處理，其完整區域（標題、內容、數字、學期及格式）均保持原樣，不因整理新學期而自動替換。必須先人工辨識區域邊界，於私有輸出記錄原檔與成品對應的頂層 OOXML 區塊，再逐區比對。保留區可能包含歷史數字，交付時明示其依要求未更新；不能稱作本期統計。

使用 scholarship.word_guard 驗證保留區 XML 與不應改動的套件內容；這是結構檢核，不取代來源核對或 Word/PDF 渲染後逐頁視覺檢查。新增申請人列可能改變頁數，不得為了強行維持頁數縮字或變更格式。例外、來源與待確認事項放私有外附說明，不插入原表單。

範本搜尋優先使用私有設定中的使用者指定範本資料夾，與申請資料來源分開。實際 Drive URL、資料夾 ID、版本資訊與原始範本僅存私有；公開倉庫只保存這項規則。每次需要取得範本時驗證可讀權限、檔案類型、名稱及版本；不要把登入頁當範本，也不要宣稱讀取尚未取得的內容。當次使用者明確指定的本機原檔可直接作為權威範本；多個候選無法判定時先保留差異、再請使用者選擇，不能靜默套用不同版型。

交付可下載 DOCX，並保留來源對應、保留區檢查及視覺檢查紀錄。公開 regression tests 只使用合成 OOXML，不含真實申請人或範本內容。

## Excel 與 Word 成績對應及跨獎項核對

REQ-023：先依姓名/學號配對歷史 Excel 個人表與 Word 列，檢查表頭、公式、儲存格值及顯示取位。歷年必修對應大學部 M2；前一學年依目前年級二至七年級對應 M8 至 M13；平均以兩者完整精度各占一半，最後 ROUND_HALF_UP 至兩位。歷史 Word 發現欄位倒置，須揭露而不學成通則；預設依欄位語義填寫，使用者明示另有意圖時再調整。模板 N2 若固定引用錯誤年級，不得將其數字直接搬到 Word；不因此擅改 Excel 原公式。輸入不完整、缺值或非適用仍不可填零，不擅自新增碩士或體育範本沒有的成績欄。保存私有欄位映射與驗算證據，不能僅驗證成品等於中間資料。

REQ-024：未申請系上其他獎學金須依當期已提供完整批次，按學號比對不同獎項；同獎項重複附件只算一次。只有單一獎項且覆蓋完整、身分無歧義才勾選，多獎項不勾，資料未完整或身分未解決則待確認。原表自行勾選與跨批次推導分別保留；不可把申請與已獲獎混淆，不宣稱涵蓋未提供資料。
