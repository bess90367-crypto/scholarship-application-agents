# Word 原格式與人工保留區

適用 REQ-022；範本來源依 REQ-017 與 rules/template-folder.md。每次產出申請名單 Word，直接複製使用者指定歷史 DOCX，只替換有來源依據的當期申請人資料與允許更新的標題。保留字型、字級、顏色、段落、表格欄寬、合併、邊框、頁首頁尾、頁面及列印設定；不得重新設計或新增說明區。表格容量不足時只複製同類原始列，保持列與儲存格格式，並檢查跨頁排版。原名單個資不得殘留於新的申請人區。

「目前系上各獎學金狀況」與「各獎學金申請人數」由使用者人工處理，其完整區域（標題、內容、數字、學期及格式）均保持原樣，不因整理新學期而自動替換。必須先人工辨識區域邊界，於私有輸出記錄原檔與成品對應的頂層 OOXML 區塊，再逐區比對。保留區可能包含歷史數字，交付時明示其依要求未更新；不能稱作本期統計。

使用 scholarship.word_guard 驗證保留區 XML 與不應改動的套件內容；這是結構檢核，不取代來源核對或 Word/PDF 渲染後逐頁視覺檢查。新增申請人列可能改變頁數，不得為了強行維持頁數縮字或變更格式。例外、來源與待確認事項放私有外附說明，不插入原表單。

範本搜尋優先使用私有設定中的使用者指定範本資料夾，與申請資料來源分開。實際 Drive URL、資料夾 ID、版本資訊與原始範本僅存私有；公開倉庫只保存這項規則。每次需要取得範本時驗證可讀權限、檔案類型、名稱及版本；不要把登入頁當範本，也不要宣稱讀取尚未取得的內容。當次使用者明確指定的本機原檔可直接作為權威範本；多個候選無法判定時先保留差異、再請使用者選擇，不能靜默套用不同版型。

交付可下載 DOCX，並保留來源對應、保留區檢查及視覺檢查紀錄。公開 regression tests 只使用合成 OOXML，不含真實申請人或範本內容。
